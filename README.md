# PagePilot

AI Powered Word 增强工具。面向 Windows 10 21H1、Word 2010 的原生桌面加载项，集成固定版本 Chatbox 1.20.3。

当前版本：**0.4.7**。修复大文档正则查找与自动导航长时间无响应；新增可切换的 Acrobat 专业无边框风格；使用惰性位置索引、滚动几何复用和局部像素采集改善高亮响应。见 [发布说明](docs/RELEASE-v0.4.7.md)。

## 当前验证状态

本机真实测试环境：Windows build 26300、Word 16.0.20430.20180、64 位。用户已确认 0.4.3-test.1 在目标机管理员环境成功启用；**0.4.7 的完整 Word 2010 功能验收仍需目标机验证，不能把本机测试当成目标环境测试。**详细记录见 [验证报告](docs/TESTING-v0.4.7.md)。代码通过 Office 2010 PIA 编译，32/64 位部署回归通过，避免将 Office 新版特性作为基本功能前提。

## 使用

1. 将完整便携压缩包解压到固定目录，例如 `D:\APP\PagePilot`。
2. 关闭 Word，运行 `PagePilot.Manager.exe` 并选择“启用此版本”（`Enable.cmd` 也是同一 exe 的快捷入口，不依赖 PowerShell）。默认注册当前用户；管理员 Word 可改选“整台电脑（管理员环境，需管理员权限）”，以管理员身份启用机器级 COM 和 Word 加载项注册；没有 MSI、ClickOnce 或安装向导，不创建“已安装的应用”条目。
3. 点击“启动 Word 并验证”，确认连接和功能区加载成功。再使用 **PagePilot** 选项卡中的正则替换、自动导航或 AI 助手。
4. 在 Chatbox 原有设置中配置模型供应商与 API Key。密钥不包含在发布包中。
5. 更新建议按版本解压到新目录，在新版管理器中启用；旧目录保留以便回退。停用也使用管理器，移动目录前先停用、移动后重新启用。详见 [部署与更新](docs/DEPLOYMENT.md)。

这是准便携程序：Word 自动加载必须保留所选范围的注册项；机器级回退记录存放于 `%ProgramData%\PagePilot.Deployment`，仅管理员和 SYSTEM 可写；Chatbox 设置和会话保存在 `%APPDATA%\PagePilot`，本地规则和操作备份默认保存在 `%LOCALAPPDATA%\PagePilot`，日志默认保存在其 `logs` 子目录；可在管理器中自定义这些位置。不会修改其他加载项或创建系统启动任务。卸载列表中没有条目，不代表系统或管理工具无法检测进程和文件。

## 0.4.1 部署与诊断

部署器采用三页导航：部署与验证、存储与日志、诊断详情。Word 占用时可请求正常关闭，或确认未保存内容丢失后强制关闭并继续部署；实际加载成功后才显示“已验证”。支持自定义配置文件、数据/会话/日志目录，详细事件日志、日志轮转、**一键打开日志文件夹**及诊断包导出。参见 [配置与日志](docs/CONFIGURATION-AND-LOGS.md)。

## 功能

* **统一图标**：翡翠、海蓝、石墨三套配色，可在设置中预览并即时切换；设置采用通用齿轮图形。

* **原生正则侧栏**：输入即查找、后台取消、单击跳转、可见区域实时高亮、虚拟化结果列表和一步撤销；最多一百万项匹配。.NET 正则、大小写选项、选区范围、捕获组替换、命中预览与定位、执行前内容一致性校验、500ms 正则超时。`^` / `$` 按 Word 段落匹配。为保护结构，替换不跨段落、单元格或分页符，不插入这些控制符。正文与正文表格是初始范围，页眉/页脚等可通过相应 MCP 工具处理。
* **无侵入导航**：综合现有大纲、标题样式、中文数字/阿拉伯数字/英文序号/罗马数字以及字号、粗体和段前间距，也支持 `级别|正则` 自定义规则提取段落位置；不写样式、不设大纲级别、不增加隐藏书签。文档变化后提示更新，点击“分析 / 刷新”重读文字及格式；同长度文字变化在跳转前校验。目录采用展开时加载子节点的可折叠多级树，可取消分析；设置支持九级独立字体、字号、粗体、颜色和窗格背景，单击即可将标题定位到视图上部；顶部留白可在设置中调节。展开“AI 目录要求”可指定只识别大标题或识别全部层级；直接使用现有 HTTPS OpenAI 兼容默认模型，显示进度并可取消，不再另开 AI 界面。目录更新默认自动批准，可在侧栏关闭后手动确认。AI 可调用 `pagepilot_set_navigation` 返回结构。明确选择“应用大纲级别”或让 AI 应用层级时才修改文档，可另选 Word 原生多级编号。
* **AI 助手**：真正的 Chatbox 1.20.3，独立窗口与 Word 侧栏可随时切换并保留草稿，保留其原生供应商、会话、附件、模型与 MCP 设置。接入 word-mcp-live 的全部 120 个工具，另有 PagePilot 上下文、导航、层级、西文格式、表格标准化、原生题注、版本能力指导、对象检查与实时对象编辑工具，共 132 个。完整参数见 `docs/tool-inventory.json`。
* **批准**：默认每个修改工具手动批准，显示工具名和参数；在对话输入栏点击盾牌，二次确认后变为红色闪电、开启自动批准；仅对当前文档、本次 Word 会话有效，切换文档或重启后恢复手动。正则替换和手动应用大纲无需 AI 批准。模型没有修改批准模式的工具。拒绝后不执行。
* **恢复**：原生批量修改和实时 MCP 修改前写入包含未保存编辑的 Flat OPC XML 备份，可用 Word 打开。文件工具修改前复制文件备份。上游实时工具尽可能组合撤销；旧版 Word 不保证一次 Ctrl+Z 撤销整个操作。

## 通信

`Chatbox → stdio MCP → 当前用户专用 Windows 命名管道 → Word 主线程`。

PagePilot 不监听 HTTP/TCP 端口。命名管道采用当前用户 ACL、随机名称和每次启动生成的会话令牌。模型供应商 API 是用户配置的出站 HTTPS 请求。整个工具目录均通过 stdio 发布，不使用 SSE 或 streamable HTTP。

## 实现与边界

加载器采用 .NET Framework 4.8 COM Add-in 和 Office 原生 CustomTaskPane。正则/导航分别使用独立的 WPF 侧栏（COM 宿主通过 ElementHost 承载），**不是 VSTO 部署包**，从而不需要额外安装 VSTO Runtime。Word 2010 的 32/64 位加载使用 AnyCPU 和分别注册的用户 COM 视图；AI 运行组件为 x64，因此便携包需要 64 位 Windows。

MCP 的“全覆盖”指全部上游工具及参数可发现、可调用；不是声称 Word 2010 支持新版 Word 的每项能力。实时编辑与关闭文件编辑是两类工具，已打开文档优先使用 `word_live_*`。AI 每次操作前读取 `pagepilot_capabilities`，逐项获知可用性及前置条件；Word 2010 的批注回复/解决会提前拦截。详细覆盖说明见 `docs/MCP-COVERAGE.md`。上游 `add_digital_signature` 只生成签名说明/元数据，**不是基于证书的加密数字签名**。本次未引入数字一致性核对等新业务功能。

AI 提供可切换的侧栏与独立窗口；正则与导航各有独立图标和可独立开关的 WPF 侧栏；设置保留左右分栏的独立 Electron 窗口，仅加载本地设置页；关闭后短时间复用进程，2 分钟隐藏闲置后释放。打开设置不会同时打开 Chatbox，可直接进入原有模型设置。PDF 转换已修复上游会退出整个 Word 进程的问题。新增对象级编辑详见 [接口与边界](docs/OBJECT-EDITING.md)。复杂嵌套结构、OLE 内部文档、全部图表/公式内部属性及 Word 原生版本比较尚未全面覆盖。

## 构建

需要 .NET SDK、.NET Framework 4.8 开发引用、Office 2010 PIA、Extensibility 引用、Node.js 和 Python 3.12。`build.ps1` 编译加载项和独立部署管理器；`scripts/Prepare-Portable.ps1` 从锁定来源准备运行组件；`scripts/Package.py` 打包白名单内容。构建依赖不要求安装到目标机。
