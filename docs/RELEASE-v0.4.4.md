# PagePilot 0.4.4

修复通过 OpenAI 兼容配置使用 DeepSeek 时，首轮正常、第二轮显示“连接失败”的问题，并汇总最近的请求头和部署器改进。

## 连续对话

- 以前只有内置 DeepSeek 配置会保留历史推理内容。现在根据 DeepSeek 模型名或官方 API 主机识别兼容配置，保留服务端返回的 `reasoning_content`，不修改用户保存的会话。
- 同一次回复中的相邻并行工具调用保持在同一条 assistant 消息中，并与结果配对，避免把没有独立推理内容的调用拆成额外回复。
- 其他模型继续沿用原有的历史推理过滤规则。不会关闭 DeepSeek 思考模式，也不会伪造推理内容。
- 模型被第三方网关改成完全不含 DeepSeek 的别名且主机也非官方地址时，无法可靠自动识别；请使用实际 DeepSeek 模型标识。

## 请求头

- Chromium/Electron 默认请求标识移除 `Electron/...`、`PagePilotChatbox/...`，使用 `Chatbox/1.20.3`；鉴权、供应商自定义头和请求正文保持原逻辑。
- 程序仍使用 Electron 运行时；供应商 SDK 可使用自身的请求头，不能据此声称所有头与官方 Chatbox 完全相同。

## 最新部署器

- 支持当前用户和整台电脑两种注册范围。管理员 Word 可使用机器级 COM 和 Word 加载项注册；启用、停用及回退均支持该范围。
- “替换旧注册”备份并删除当前账户及机器级的旧 PagePilot 注册，再注册新目录，无需运行旧版安装器。遇到明确属于其他程序的注册会拒绝覆盖。
- 失败恢复、双范围回退和中断后的重试；机器级备份使用受保护的公共目录，回退保留安全检查。
- 管理器提示与所选范围匹配；诊断增加进程权限、Word/.NET、注册表视图及相关加载环境，避免收集密钥和文档内容。
- 继续保持准便携：完整解压到固定目录后启用，无 MSI、ClickOnce 或系统安装条目；升级建议解压到新目录，保留旧目录供回退。

## 验证与使用

- 在旧打包代码中复现首轮 HTTP 200、第二轮因缺少历史推理内容返回 HTTP 400；修复后连续三轮、持久化后重载、并行工具、失败及未完成工具历史检查通过。
- 使用真实 DeepSeek 接口和打包代码中的历史转换器完成三轮对话，每轮调用一个合成文档工具，不读取真实文档。
- 请求头回归验证覆盖渲染器请求和主进程请求；部署回归在 x86/x64 两种进程中执行。
- 本机 Word 16 x64 验证；用户已确认此前 0.4.3-test.1 在目标机管理员环境启用成功。此版本完整 Word 2010 功能验收仍需目标机测试。

关闭 Word，将便携包解压到新目录，运行新版 `PagePilot.Manager.exe`。目标机需管理员环境时，选择“整台电脑”；提示另一范围残留旧注册时勾选“替换旧注册”。旧目录请保留。

如果原会话中已经保存了推理内容，更新后可直接重试失败消息。对于原先未保存完整推理内容的旧会话，需新建会话；程序不会编造缺失内容。

下载便携包即可使用；source 包包含 PagePilot 源码及固定版本 Chatbox 上游源码，校验值见同版本 SHA256SUMS 文件。
