# 0.4.4 验证记录（2026-10-27）

本机环境为 Windows build 26300、Word 16 x64、.NET Framework 4.8，加载项使用 Office 2010 PIA 编译。用户确认 0.4.3-test.1 已在目标机管理员环境成功启用；这不代替 0.4.4 的完整 Word 2010 验收。

## 对话回归

`node tests/conversation-history.cjs` 直接读取发布运行时中的流事件处理器、消息转换器、供应商判断表达式和 OpenAI 兼容 SDK 序列化函数，而非在测试中重新实现转换器。

- 旧 renderer：首轮 HTTP 200；含推理和工具调用的历史进入第二轮后 HTTP 400，缺少 `reasoning_content`。
- 新 renderer：本地协议校验端点连续三轮 HTTP 200，覆盖持久化后重载、并行调用配对、完整推理文本、内置与兼容 DeepSeek、其他供应商隔离、失败和未完成工具。
- 使用真实 DeepSeek 接口连续三轮通过，每轮完成一个合成文档工具调用。测试使用发布代码转换历史；没有读取真实文档，也没有将密钥写入测试输出。
- 此接口回归不等同于目标机上完整 Chatbox 界面的验收。

显式指定 `--live-config <本机 Chatbox config.json>` 可运行额外的真实接口测试，会消耗少量模型额度。默认测试只使用本地模拟服务。

## 部署与打包

- 部署回归在 x64 和 x86 进程各通过 144 项断言，覆盖机器范围、旧注册替换、双范围备份恢复、停用、回退、故障恢复和环境诊断。机器范围写入测试使用隔离的测试注册子键，未冒充真实多账户 HKLM 验收。
- Electron 隐藏测试窗口及主进程的请求头验证通过：UA 包含 Chatbox/1.20.3、不含 Electron，模拟鉴权、自定义头及正文保留。
- Release 编译通过；NuGet 漏洞数据源仍不可达，使用缓存依赖编译，未完成新的漏洞审计。
- 从 SHA-256 校验过的官方 ASAR 重放所有原生补丁，核对来源链；变更文件及完整 renderer 语法检查通过。
- 发布 ZIP CRC、9333 项运行文件 SHA-256、源码快照和发行包校验值验证。

本次不重复执行未改动的全部 Word 对象编辑、性能及多显示器测试。管理员多账户组合及 Word 2010 完整矩阵仍需目标机验证。
