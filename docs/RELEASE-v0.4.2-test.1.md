# PagePilot 0.4.2-test.1 · 管理员 Word 的机器级部署测试包

针对 Word 2010 管理员环境下，当前用户注册可能无法被 COM 激活的问题，增加可选的整台电脑注册。程序和管理器文件版本为 0.4.2.0；这是供目标机验收的测试包，并不代表 Word 2010 已验证通过。

## 目标机测试步骤

1. 将完整包解压到固定的新目录，例如 `D:\Apps\PagePilot\0.4.2-test.1`。不要覆盖正在使用的旧版本。机器级加载目录应由管理员管理，避免其他普通账户修改其中的运行文件。
2. 保存文档，完全退出 Word。机器级变更会检查所有账户、所有会话的 Word；管理器不会强制结束其他账户的 Word。
3. 如果旧版仍在当前用户范围启用：从旧目录停用旧版；或在新管理器中选择旧版本目录、选择“当前用户”，再点击“停用此版本”。如果旧版已经停用，可跳过。切换范围时遇到冲突会拒绝覆盖并给出提示。
4. 右键新目录的 `PagePilot.Manager.exe` → **以管理员身份运行**，在部署范围选择 **整台电脑（管理员环境，需管理员权限）**。也可右键 `Manager-Machine.cmd` 以管理员身份运行，它会预选机器级范围。
5. 点击“启用此版本”，完成后点击“启动 Word 并验证”。保持目标机原有的管理员环境。管理器显示“已验证”需要同时收到当前版本的 Word 连接与功能区加载回执。
6. 检查 PagePilot 选项卡、正则查找、导航、AI 窗口和侧栏；关闭 Word 后再打开复测。
7. 如果仍加载失败：保持注册状态，不要先停用；选择“诊断详情”→“导出诊断包”。同时记录 COM 加载项窗口的完整提示。

## 停用、回退与移动

- 停用：关闭所有 Word，以管理员身份打开当前启用目录的管理器，选择“整台电脑”后停用。只删除本范围下 PagePilot 的三个 COM 类、三个 ProgID 和 Word 加载项注册，不删除程序、用户配置、会话或备份。
- 回退：在同一范围选择“回退软件版本”，恢复该范围最近一次变更前的注册。首次机器级启用的回退结果是未注册；停用后的回退会恢复停用前版本。重复启用或重复停用不会覆盖有效回退点。保留旧程序目录，否则无法恢复旧版本。
- 从机器级回到旧版当前用户：先停用机器级，再从旧目录启用当前用户范围。跨范围不会自动恢复另一范围的版本。
- 移动：先停用，再移动整个解压目录，最后从新位置按原范围启用。
- 清理：确认不再需要回退后，可删除已停用的程序目录。机器级回退历史保留在 `%ProgramData%\PagePilot.Deployment`，可由管理员手动删除；删除后不能再用管理器回退。用户数据与日志默认保留，路径可在“存储与日志”查看。

## 准便携边界

运行文件始终位于解压目录，Python 和 Electron 随包提供。不安装 MSI/VSTO、不写 GAC、系统目录或 PATH，不创建服务、计划任务或开机启动项。没有安装列表条目。

Word 自动加载需要少量持久注册项：当前用户模式写 HKCU，机器级模式写 HKLM，并按实际 Word 32/64 位选择注册视图。机器级模式使其他账户的 Word 也可发现 PagePilot；其他账户如保留自己的旧注册，可能仍会遮蔽机器级版本，需由该账户自行停用旧注册。管理器不遍历或更改其他用户的注册配置。

两种范围的回退历史隔离。当前用户沿用 `%LOCALAPPDATA%\PagePilot\deployment`；机器级使用 `%ProgramData%\PagePilot.Deployment`，仅管理员和 SYSTEM 可写。模型密钥、会话、偏好和文档备份仍按用户保存，不会变成全机共享数据。

## 新增诊断

完整诊断与导出包包含：系统构建、管理器位数与 CLR、Word 文件版本与实际进程路径、每个 Word 进程的 SID/会话/提升状态/完整性级别、UAC 配置、两个注册视图中的 HKCU/HKLM 类注册与 LoadBehavior、.NET 安装版本、Office 加载策略、禁用记录数量及是否含 PagePilot、兼容性运行标记、文件读权限和下载 ZoneId，以及近期相关应用错误摘要。

只读采集，不修改 UAC 或 Office 策略，不清空禁用列表。权限不足时记录“收集失败”而不中断其他项目。系统错误只检查最近 48 小时内最新 400 条，最多返回 20 条相关事件，不能替代实际加载验证。普通管理器启动日志也记录自身权限、位数和 CLR。

诊断包包含账户 SID、本机路径与错误摘要，不收集文档正文、聊天记录或模型配置；下载标记只采集 ZoneId，不导出原始下载 URL。

## 命令行

以下变更命令须在管理员环境执行，无需目标机安装 PowerShell：

```text
PagePilot.Manager.exe enable --scope machine --verify
PagePilot.Manager.exe disable --scope machine
PagePilot.Manager.exe rollback --scope machine
PagePilot.Manager.exe doctor --scope machine --output "D:\PagePilot-diagnostic.txt"
PagePilot.Manager.exe export-diagnostics --scope machine --output "D:\PagePilot-diagnostic.zip"
```

不指定 `--scope` 仍为 `user`。随包提供机器级启用、停用、回退与管理界面 `.cmd` 快捷入口；必须以管理员权限运行，不会自动改变系统权限设置。
