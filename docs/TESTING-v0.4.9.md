# PagePilot 0.4.9 验证记录

日期：2026-11-13。实际环境为 Windows、Word 16 x64、Excel 16.0、.NET Framework 4.8、Electron 44.7.0、Python 3.12.10。使用本机 Office 15 PIA 编译。Windows 10 21H1 / Word 2010 / Excel 2010 标准版实机验收仍待完成；兼容模式和版本模拟不替代目标机验证。

## 2026-11-13 首次发送后工作区列表消失修复

首次发送会从首页切换到新聊天并重建输入组件。原实现依赖旧工作区组件监听路由事件来继承草稿，组件提前卸载时会漏掉关联：MCP 仍能通过消息中保存的工作区 ID 读取资料，新聊天界面却查询了另一个空工作区。现在在首次发送流程内等待关联完成，再导航到新聊天；普通聊天切换只刷新显示，不迁移草稿。空工作区也保留同一 ID，以便本轮生成的分析底稿出现在当前聊天。

- 新增 `node tests/workspace-session.cjs`：执行实际构建中的首页发送回调。修复前稳定失败于“新聊天挂载前工作区尚未关联”，修复后通过异步关联顺序、界面/MCP ID 一致、重新读取持久化文件、后续新聊天隔离、重复关联、过期发送拒绝和已有工作区保护。
- `node tests/workspace-store.cjs`、`node tests/workspace-context.cjs` 通过，覆盖文件组织持久化、上下文与消息顺序。
- `dist/Browser/electron.exe tests/workspace-ui.cjs --no-screenshots` 的 13 组检查通过：真实隔离预加载/进程通信、新聊天组件重建后文件与虚拟文件夹可见、切换旧聊天不带走草稿、尺寸/草稿/主题、整理、导出与删除。截图模式在当前桌面环境的页面捕获阶段停滞，本轮功能回归关闭截图保存，仍执行布局断言。

实际 API 与 Word 验证也已通过，见下节。源码与发布运行文件同步，测试专用注入已还原。

## 2026-11-13 原生 Excel 增强与真实 API

本机使用 Excel 16.0 和 Word 16。默认生成 Excel 2010 兼容公式、图表和版本 14 原生透视表；尚未在 Excel 2010 标准版实机验收。

- `tests/workspace_excel_regression.py` 的 8 组真实 Excel 回归通过：工作表新建/复制/改名/删除、文本与区域写入、相对公式填充、表格、统计、图表、原生透视表缓存及刷新；更改源值后总利润从 165 更新至 215，旧文件哈希保持不变。
- 兼容转换通过：大小写不敏感的精确查找、未匹配值、空值填补、文字修剪、数值转换、去重、排序、筛选。已验证原生排序和筛选与生成结果。
- 新版函数采用实际探测；本机支持的 SORT 动态数组公式已实际计算并从保存后的缓存读回 1、2、3。默认 2010 模式拒绝新版函数。宏/外部公式、过期版本、无效区域/工作表和公式错误被拒绝；失败批次不发布半成品。
- 独立 Excel 全程不可见；创建另一实例作为现有用户工作簿，验证其内容与进程保留。强制终止测试工作进程后，其作业内的 Excel 自动退出。
- `NativeChatboxIntegration.exe <仓库目录> <本机Chatbox配置文件> workspace-send` 通过：测试使用独立 Word 文档和聊天配置，在真实 Chatbox 输入框发送两条请求，经当前配置的 `deepseek/deepseek-flash` API 与 stdio MCP 执行。第一条从文件读出每次生成的随机校验标记；首次发送后界面文件列表和 MCP 工作区 ID 一致。第二条实际调用新增 Excel 工具，创建 Profit 公式、“原生透视”和“统计”工作表，并读回结果。
- 实际 API 保存的文件具有真正的 PivotTable 和缓存；Excel 文件读回 East 2025/2026 利润 40/50、West 30/45，总利润 165。来源 XLSX 哈希不变，Word 正文和对象未改变。生成底稿自动出现在工作区；切换新聊天、切回原聊天、重新加载聊天界面后参考文件和底稿仍可见。
- 本轮沿用真实 API 配置，凭据只注入测试进程内存；测试配置写入会剥离凭据，不复制用户聊天。测试入口临时追加的诊断代码在退出前还原。证据保存在 `.temp/workspace-send-live/result.json` 和合成资料会话记录中，不进入发布包。

17 组原有解析/离线分析回归再次通过。完整原生工具参数见 `workspace-tool-inventory.json`；能力与版本边界见 `WORKSPACES.md`。

## 版本构建与部署回归

加载项与管理器 Release 编译均通过，零警告、零错误，程序集版本均为 `0.4.9.0`。管理器从实际程序集读取版本，避免界面或日志继续显示旧版号。32 位与 64 位部署测试分别通过 144 项检查，涵盖用户/机器两种注册范围、升级回退、故障恢复、配置保留与权限边界。
