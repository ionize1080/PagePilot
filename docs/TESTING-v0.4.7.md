# PagePilot 0.4.7 验证记录

日期：2026-10-28。真实环境为 Windows build 26300、Word 16.0.20430.20180 x64、200% DPI、.NET Framework 4.8。使用 Office 2010 PIA 编译；没有把本机结果视为 Word 2010 实机验收。

## 大文档与位置正确性

用户指定的 `244732.SH.docx` 约 22 MB，正文 XML 约 33 MB；Word 实际报告 15,809 段，包含 137 个表格和 38 张图片。原文只读打开，未作为发布资源上传。

原实现对整篇文字逐字符映射 Word 位置，并导出包含图片的完整 WordOpenXML；大样本会产生大量同步 COM 调用。新实现保留不可变文本及惰性位置索引，导航直接流式读取已保存 DOCX 的正文/样式。Word CP 位置不等同于 UTF-16 下标，仍需处理域、表格结束符、公式与对象的投影差异。

真实 Word 集成宿主（插件代码在 Word 进程外运行，包含跨进程 COM 开销）的测量如下。查找为 `\d+`，复用查询为 `[0-9]{2,}`；时间包含输入防抖。它们是单次记录，不是固定延迟保证。

| 样本 | 匹配数 | 首次查找 | 复用查询 | 导航 | 取消响应 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 6,000 段合成正文，附表格、域、隐藏文字和 emoji | 6,001 | 1,009 ms | 325 ms | 4,382 ms | 66 ms |
| 用户指定大样本 | 16,365 | 1,558 ms | 706 ms | 20,613 ms | 45 ms |
| 公开政府表单 | 7 | 1,147 ms | 181 ms | 5,004 ms | 83 ms |
| 公开年度报告 | 146 | 1,646 ms | 254 ms | 599 ms | 44 ms |
| 公开中文复杂文档 | 152 | 2,976 ms | 179 ms | 2,500 ms | 41 ms |

- 大样本初始映射只需 7 次文本范围读取；分布抽查约 100 个真实 Word 范围，逐个与匹配原文核对；重新输入复用同一索引。表单中存在部分 Range 投影不一致，改为在有界范围使用原生精确查找，并同时验证正文和原始出现位置，不能把重复文字误认成目标。
- 替换预览异步更新、文档正文/保存状态保持、导航取消及风格往返切换均通过。大样本导航期间宿主消息处理间隔 p95 为 48 ms，最大 306 ms；查找最大 444 ms。预算无法打断单次 Word 调用。
- 87 项索引回归：20,000 个匹配仅一次初始读取、非线性 CP 映射、已定位结果复用、非零起点空选区、域结果及取消。抽查后累计 983 次读取，无需为全部匹配建立逐字符映射。
- 17 项核心回归通过，包括正则超时、Unicode、捕获组、段落/表格边界和 100,001 项匹配（144 ms）。
- 55 项导航回归通过；50,000 段合成识别约 1 秒。现有《黎曼猜想》真实 Word 测试保留 8 个章节，排除封面/纯公式；最终导航约 734 ms，实际跳转、懒加载和取消通过。另验证现有《指数时间猜想》样本。

## 公开文档

使用 `tests/corpus/manifest.json` 中 50 份公开 DOCX，文件来源和 SHA-256 固定。本次新下载成功 45 份；5 个来源返回 HTTP 403，使用此前下载且哈希一致的副本。涵盖 13 份中文、33 份英文、4 份威尔士语，包括高校资料、政府表单及年度报告。部分报告共享模板，不等于 50 种独立版式。

- 独立 XML 回归：16,726 段、1,255 个候选标题、8,326 项结构/样例检查通过，最终约 2,129 ms。
- 真实 Word 回归采用生产的索引读取和原生回退路径，逐一检查标题 Range、正文及只读文件完整性。全部 50 份、18,442 个原生段落完成；133 项选定标题/排除及源文件哈希断言通过。
- 最终一轮含打开文件、分析与原生 Range 核验的时间，中位数 3,810.5 ms，最大 16,366 ms；不等于纯算法耗时。
- 断言只覆盖选定正反例，未人工标注全部段落，不报告总体识别准确率。原文档不进入便携包或源码包。

## 高亮和设置

- 真实 Word 正则输入、单击定位、批量替换、单步撤销、域后映射及 XML 不变检查通过。
- 连续滚动的可见起点从 0 变为 87，18 个测量片段，测试动作 802 ms；最大片段 195 ms。记录到 7 次几何平移复用、157,252 个局部采集像素；100% → 125% 缩放自动更新通过。此为进程外宿主，不能把 4 ms 软预算解释为实测每帧 4 ms。
- 像素回归验证自定义有色底纹、黑字不变、灰字不变亮、重叠标记不重复染色，以及滚轮/水平滚动/键盘/窗口变化钩子释放。
- 设置页 620/880 像素宽度通过：专业风格保存、零边框预览、浅蓝选中态、自定义多彩配色保留、切回恢复、九级配置、控件无横向溢出。WPF 真实导航窗格资源检查确认边框从 1 变为 0，切回后恢复。
- 在已安装 0.4.7 的 Word 中，以《指数时间猜想》实际操作设置切换为 Acrobat 风格、点击第 4 节定位，确认中性灰、浅蓝选中态及零边框。实际输入 `ETH` 得到 71 项，插件日志记录查找 71 ms（另有 140 ms 输入防抖）；滚轮滚动后高亮正确随正文移动，黑字和灰色文字保持清晰，未见旧位置残影。

## 安装、构建与范围

安装目录为 `D:\APP\PagePilot-0.4.7\PagePilot`，保留旧版目录供回退。新建 Word 自动加载，命名管道实际返回 0.4.7。大样本进程内导航两次记录为 5,387 / 5,095 ms，均得到 589 个标题；第二次启动与连接 2,367 ms，打开导航调用返回约 574 ms。这些结果与上面的进程外测试应分别解读。

对大样本使用 computer-use 时，窗口状态采集引发 Word 原生线程长时间无响应；两次托管调用栈均没有正在执行的 PagePilot 查找/导航代码。关闭插件连接后重新只读打开同一文件，再次在窗口状态采集后复现。因此这部分大型文档的辅助功能自动化不能作为通过项；大样本功能与响应指标采用前述真实 Word API 集成及安装后日志验证。测试仅结束自己创建且只读打开样本的 Word 进程，未关闭用户文档。

加载项及管理器 Release 编译通过；32 位和 64 位各 144 项部署回归通过，覆盖注册、回退、故障恢复、目录和配置校验。本机代理不可用，使用缓存依赖及离线源配置完成构建；NuGet 漏洞审计未验证。

未重新执行不受本次变更影响的真实模型 API 测试；前版结果保留在 [0.4.6 报告](TESTING-v0.4.6.md)。Win10 21H1 / Word 2010 完整实机矩阵、混合 DPI、多显示器、远程桌面及所有嵌套对象组合尚未穷尽验证。

## 设计依据与复现

采用保留几何、资源复用、局部更新和滚动位移复用原则，参考微软的 [Direct2D 性能指南](https://learn.microsoft.com/en-us/windows/win32/direct2d/improving-direct2d-performance)、[DXGI 局部呈现与滚动更新](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/dxgi-1-2-presentation-improvements) 和 [WPF 二维图形性能](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-2d-graphics-and-imaging)。实现仍是兼容的 Win32/GDI+/WPF，并未改为 DirectX 后端。专业配色参考 [Adobe Spectrum](https://spectrum.adobe.com/page/using-color/) 和 [Acrobat 书签界面](https://helpx.adobe.com/acrobat/using/page-thumbnails-bookmarks-pdfs.html)。

主要入口：`SearchSnapshotRegression.csproj`、`LargeDocumentIntegration.csproj`、`PhysicalIntegration.csproj --local-only`、`NavigationIntegration.csproj`、`NavigationLiveCorpus.csproj --indexed`、`NavigationCorpus.csproj`、`verify_live_corpus.py`、`navigation-settings.cjs` 及 `DeploymentRegression.csproj`。测试所需用户样本由运行者显式传入，不打包私人原文或本地凭据。
