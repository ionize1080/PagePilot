# PagePilot 0.4.1 验证记录 — 2026-10-26

本次环境：Windows build 26300、Word 16.0.20430.20180 x64、普通用户权限、200% DPI、Office 2010 PIA、.NET Framework 4.8。0.4.0 的性能与对象编辑测试保存在 [历史记录](TESTING-v0.4.0-rc.1.md)，不作为本次重新执行的结果。

## 本次已执行

- 加载项及管理器 Release 编译通过。NuGet 漏洞数据源受本机代理连接失败影响，使用已缓存依赖完成编译；漏洞审计未通过验证，也未标记为安全。
- 36 项部署回归通过：配置格式与相对路径、非法配置、迁移保留原文件且不覆盖目标、拒绝嵌套目录、日志脱敏与轮转、加载回执双条件、PID 重用/错误路径拒绝；32/64 位独立注册子键中的启用、重复启用、升级回退、失败恢复、停用恢复、含空格/中文路径、Word 清除连接标记后回退、诊断包白名单。
- 强制结束测试只操作明确创建的测试子进程，先验证用户归属；未强制关闭用户 Word 文档。其他账户/会话的拒绝逻辑已代码检查，未做多账户实机矩阵。
- 17 项核心测试通过，包含结构边界保护、正则超时、Unicode 和 100,001 项匹配（本次约 138 ms，非目标机承诺）。
- 模拟 Word 14、Word 16、无文档和受保护文档的能力矩阵通过；132 项工具与全部 120 项上游工具保留。
- JavaScript 变更文件语法检查通过。
- 真实 Word 冷进程启动：从含空格路径部署，普通权限连接 Word 16 并加载功能区。发现并修复 URI 空格转义与 CLR COM 加载不兼容的问题；采用与 RegAsm 输出一致的 CodeBase 表示后验证通过。
- 实际加载回执检查和 PagePilot 功能区视觉检查通过。设置窗口启动完成，Word 请求和 Electron 生命周期日志写入默认日志目录；设置可交互约 627 ms（单次样本）。
- 部署器主页、存储页的 200% DPI 布局及非活动页隐藏检查通过，日志快捷入口使用独立处理函数，避免依赖不可见页面按钮。
- 实际点击侧边栏打开日志文件夹成功；正常关闭本次验证创建的 Word 空白窗口成功；部署回退成功，恢复测试前的 0.4.0-rc.1 注册。
- 实际诊断包导出完成并返回 0，ZIP 只含诊断报告、事件日志和部署记录；Electron 自定义日志目录/敏感字段脱敏、Python 自定义目录与日志级别检查通过。

## 尚未覆盖

Win10 / Office 2010 本次发布的完整实机验收尚未完成。用户提供的历史日志可以确认旧版连接过 Word 14.0 并打开相关界面，不能证明首次失败的根因，也不能替代 0.4.1 验收。模拟版本矩阵与 Office14 PIA 编译不等于目标机测试。

未重新执行上一候选版的全套真实对象编辑/模型性能测试；本次未改变这些工具的编辑逻辑。跨账户部署、全部 Office 禁用策略、网络盘、混合 DPI、无响应 Word 且存在未保存文档等组合仍需目标机测试。日志按应用操作埋点，无法保证强制终止/系统崩溃时最后事件落盘，总日志目录没有固定容量上限。

## 复现

运行 `tests/DeploymentRegression.csproj`、`tests/CoreTests.csproj`、`tests/capabilities.py`。部署测试使用随机的当前用户测试子键和临时目录，不改实际加载项注册。命令行 `enable --verify --output <报告>` 可检查真实安装；请只在自己的测试环境使用，并保存/关闭 Word。

发布检查须包含完整运行文件清单、ZIP 白名单与 SHA-256 校验；用户诊断包、会话、密钥和绝对路径测试输出不得进入源码或发布资源。
