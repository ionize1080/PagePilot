# 0.4.2-test.1 测试记录 · 2026-10-27

## 本地结果

- .NET Framework 4.8 / Office 2010 PIA 构建成功；管理器零编译错误、零警告。加载项使用已缓存依赖构建，NuGet 在线漏洞数据获取失败（本机代理不可用），因此本次未完成新的在线依赖审计。
- 部署回归分别以 64 位和 32 位进程运行，每次 108 项通过。覆盖两种范围与两个注册视图、启用/升级/停用/回退、失败注入恢复、中断事务恢复、回退部分完成后重试恢复、重复操作保留回退点、错误目录停用拒绝、跨范围遮蔽拒绝、异常回退路径拒绝、旧版用户回退记录兼容、权限与环境采集。
- 注册变更测试全部使用隔离的 HKCU 测试子树；机器级逻辑重定向到独立测试子树。没有在本机对正式 HKLM COM 注册执行启用/停用/回退。
- 机器级回退记录权限策略通过内存 ACL 测试：接受管理员所有者和受保护权限，拒绝非管理员可写或非可信所有者。实际 ProgramData 目录创建与管理员跨账户回退待目标机确认。
- 用真实管理器窗口检查默认用户模式、机器级选择项、文字与操作区布局；未发现截断或重叠。旧“建议改用普通用户”提示已替换。
- 扩展环境诊断在本机实际读取提升令牌、完整性 SID、UAC 和两种注册视图；32 位诊断进程也通过检查。诊断不启动 Word、不进行 COM 激活或修改注册。

## 验证边界

本机为 Windows build 26300 / Word 16 x64，当前执行账户没有提升权限。本次没有声称已完成真实 HKLM 写入或管理员 Word 加载验证，Word 2010 32 位完整实机验收需在目标机进行。

目标机请按 [测试步骤](RELEASE-v0.4.2-test.1.md) 检查：首次机器级启用、重启 Word 后加载、侧栏功能、机器级停用、停用后的回退、迁移目录后重新启用。如失败，请在停用前导出扩展诊断包。
