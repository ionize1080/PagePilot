# PagePilot 0.4.8 验证记录

日期：2026-11-12。实际功能环境为 Windows、Word 16 x64、.NET Framework 4.8、Electron 44.7.0、Python 3.12.10；使用本机 Office 15 PIA 编译。未完成 Windows 10 21H1 / Word 2010 实机矩阵，不能将版本模拟或兼容模式视为目标机验收。

## 真实 Qwen 与 Word

使用用户提供的真实凭据，密钥仅从用户指定文件读取到内存，未加入源码、发布包或测试结果。请求使用 Qwen `qwen3.7-plus` 和 Token Plan 的 OpenAI 兼容接口。测试内容是合成研究资料。

- 真实 stdio MCP：读取 Markdown、DOCX、PPTX 和 PDF 的相关片段，实际调用批量读取，核对 ORCHID-731 和 20% 增长率。
- 图片及扫描 PDF：分别实际调用视觉读取；模型识别红柱 40、蓝柱 60 和图内编号。修复了把 MCP 图片仅序列化为 base64 文本的问题，OpenAI/兼容接口发送实际图片块，保留并行工具调用与返回的配对。
- 分析：读取 Revenue 工作表，计算 Revenue − Cost，按 Region 和 Year 透视；East 2025/2026 为 40/50，West 为 30/45，并核对本机保存的 XLSX。
- 实际 Chatbox 生产界面与 SDK：通过真正的浏览器 File 句柄走原附件预处理入口，核对仅生成小型引用；连接实际两个 MCP 服务，Qwen 查看图片、生成分析底稿、读取当前 Word 内嵌 PDF，取得 live range 句柄并把结论写入真实 Word 测试文档。写入后读回 Word 内容，验证原文和嵌入对象保留。测试宿主的自动批准仅绑定自己创建的合成文档。
- 测试发现兼容服务偶发先发送工具 ID、后发送名称；新增有界流式片段拼接，在名称/参数完整前不调用工具。对实际发布 SDK 中四条流式处理路径回放延迟名称、名称分片、交错调用、完整参数和截断情况；不完整调用明确失败。修复后实际 Qwen + Word 内嵌 PDF + 写入的完整链路通过。
- 针对 Folio 曾出现的末尾 system 消息问题，直接执行本次发布代码中的 Word/工作区上下文注入：新会话、旧会话、切换文档/工作区、图片和工具继续调用均保留原顺序；新增上下文只附在对应用户消息里，原始历史不变。

此前完整链路曾因模型把文档显示名当成完整路径而被正常拒绝；工具说明和上下文提示补充必须使用 `document.path`，最终测试通过。测试失败未绕过文档绑定或批准机制。

## 本地解析、组织与计算

- 17 组 Python 回归通过：文字/HTML/PDF、扫描页提示、DOCX 表格/标题、XLSX 坐标/公式缓存、PPTX 备注/图片、旧 DOC/PPT、分页/版本校验、8 段共享预算、100 MB 默认限制、ZIP 解压保护、路径逃逸、隐藏文件、嵌入附件/外部链接、公式计算和留存底稿。
- 对实际 Office 文件生成的旧 DOC/PPT 样本读取当前正文/幻灯片；生产解析过程不启动对应 Office 应用。
- 计算核对分组/透视结果、实际缓存值、可查看公式、源文件 SHA-256 不变、空值/不安全表达式/除零拒绝、公式依赖/循环/反向范围、源公式文本保留，以及以等号开头的普通文本不会被执行。解析与计算测试前后 Excel 进程集合不变。
- 虚拟目录存储回归：嵌套、重命名、多选移动、同级排序、循环拦截、12 层上限、同路径引用去重、删除保留原文件、首选项持久化和新聊天草稿继承。
- 2,505 个文件的目录仅枚举名称，分两批扫描 2,000 / 506 项（包括根来源项），实测约 1,032 / 281 ms，总计约 1,328 ms。未读取正文。此为本机一次测量，不承诺所有磁盘固定延迟。

## UI 和 Word 回归

- Electron 隔离预加载与真实文件输入测试通过。小窗在 360、480、900 像素窗口宽度无横向溢出，草稿保留，深色显示、首选项持久化及聊天隔离通过。
- 实际渲染器拖放事件经预加载与持久化存储：文件拖入/拖出、虚拟文件夹嵌套、新建、F2 重命名、删除子树，原文件保留。导出底稿与源底稿逐字节相同，删除仅作用于所选管理底稿，导出副本仍保留。收起后释放聊天可视区域。
- 独立真实 Word OLE 测试：创建 Packager PDF 与图片，提取真实 payload；正文和 Saved 状态不变，编辑后的旧句柄拒绝。Word 导出时重建的 OLE ObjectID 从编辑指纹中排除，仍保留实际关系和二进制内容。
- 114 项真实 Word 对象检查/编辑断言、17 项核心回归、批准取消/重入/显式启用/切换文档重置通过。原有聊天历史、并行工具和失败返回回归通过。
- 设置 620/880 像素布局与导航偏好保存通过。32 位和 64 位部署测试各 144 项通过；包括迁移不覆盖已有文件、路径配置、回退及故障恢复。本次未改动注册机制。
