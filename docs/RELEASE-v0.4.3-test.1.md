# PagePilot 0.4.3-test.1 · 直接替换旧注册

解决机器级部署时被“另一部署范围仍有 PagePilot 注册”阻挡的问题。新管理器可自行备份和清理旧注册，不需要寻找旧版管理器。保留 0.4.2 的扩展环境诊断、停用与回退功能。

## 目标机操作

1. 完整解压本包到新的固定目录，保存文档并完全退出所有 Word。
2. 右键 `Manager-Machine.cmd`，选择“以管理员身份运行”。使用与原 Word 相同的 Windows 账户。
3. 确认范围为“整台电脑（管理员环境，需管理员权限）”。勾选 **替换旧注册（备份后删除旧注册，再启用此版本）**。
4. 点击“启用此版本”，再点击“启动 Word 并验证”。无需先停用旧版。
5. 如果仍无法加载，先导出诊断包，再考虑停用；请勿在导出前移除注册。

也可右键 `Replace-Machine.cmd` 以管理员身份运行，直接执行替换启用。此快捷方式完成注册后，仍需在管理器中选择机器级范围并验证 Word 加载。

## 替换范围与回退

- 按实际 Word 位数处理对应注册视图，仅备份、删除 PagePilot 的三个固定 COM 类、三个 ProgID 和 Word 加载项键。先清除当前账户中的冲突注册，再清除所选机器级旧注册，写入新目录。旧的程序集版本子键也会清理。
- 不删除旧程序目录、模型设置、会话、文档、日志或其他加载项，不清理其他账户的注册配置。不完整的 PagePilot 注册可以重建；若明确指向其他厂商的组件则拒绝删除。
- 两个范围的原始注册在同一机器级事务中备份。写入失败会恢复两边；事务或回退中断时保留待恢复记录，可重新回退。
- 替换完成后立即“回退软件版本”，会恢复替换前两边的注册。此类回退需由执行替换的同一 Windows 账户以管理员权限运行，且旧 DLL 仍在原位置。
- 替换后“停用此版本”会停用新机器级版本，不自动重新启用旧的当前用户版本；随后回退这次停用会恢复新机器级版本。管理器默认回退最近一次变更。
- 重复启用已正确注册且无当前用户冲突的版本，会保留原回退点。

## 准便携性

程序继续在解压目录运行；新增功能只操作必要注册项和受保护的回退记录，不安装服务、MSI、GAC 或系统启动任务。机器级记录仍在 `%ProgramData%\PagePilot.Deployment`，个人数据仍按用户保存。移动目录前停用，移动后从新位置启用。

## 命令行

```text
PagePilot.Manager.exe enable --scope machine --replace-existing --verify
PagePilot.Manager.exe rollback --scope machine
PagePilot.Manager.exe disable --scope machine
```

`--replace-existing` 只用于机器级启用。它不代表强制结束 Word；未保存的文档必须先处理。

## 验证结果与边界

64 位与 32 位测试进程各通过 144 项隔离回归，包含跨范围替换、两边精确恢复、旧版本子键清理、重复操作、跨账户回退拒绝、后续注册改动检测和回退中断重试。测试使用隔离的 HKCU 子树模拟机器注册存储，不修改本机正式 COM 注册。

本机编译通过；加载项的在线 NuGet 漏洞数据获取仍受本机代理限制，本次使用已缓存依赖。真实 HKLM 写入、管理员 Word 与 Word 2010 完整加载仍需目标机验收。本包的程序与管理器文件版本均为 0.4.3.0。
