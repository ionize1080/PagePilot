# PagePilot v0.4.0-rc.1

本次候选版集中改善启动与交互速度，扩展 Word 对象编辑，并提供不依赖 PowerShell 的半便携部署管理器。没有引入数字一致性核对等新业务功能。

- 发送前不再逐段扫描全文；目录先显示侧栏再分批读取；替换词变化复用快照，选区保持固定；AI 目录变化后保留并提示过期。
- 设置保留 Electron 视觉界面，使用轻量入口与短时窗口复用。真实 UI 检查修复了复用交互、缩放和小窗口布局问题。
- 保留原 129 个工具的参数和审批标记，总数扩展为 132。新增统一范围、对象枚举、稀疏属性修改和创建接口，覆盖表格行列/拆合/边框、节与首页/奇偶页页眉页脚、域/目录/控件/样式、既有图片/公式、文本框/形状/图表系列/OLE 属性。
- 能力报告同时考虑 Word 版本和文档兼容模式；错误文档、旧句柄和格式变化会拒绝操作。修改前备份，失败后尝试撤销并明确报告恢复状态。修复交叉引用常量和图片参数检查顺序。
- `PagePilot.Manager.exe` 提供启用、停用、诊断与回退，检测 Word 位数，只注册当前用户。按版本分别解压后切换，配置、会话、规则和备份继续保留。修复含空格路径的实际 COM 加载问题。

本机 Word 16 x64 实测：1,000 段轻量身份读取 P95 约 13 ms；设置首次约 583 ms、重开 P95 约 27 ms；10 次 AI 新进程启动，输入框 P50 2.10 s / P95 2.46 s，MCP 准备 P50 4.01 s / P95 4.49 s。这些是本机进程启动测试，不代表重启电脑后的冷磁盘或 Word 2010 速度。

提供完整便携包、含固定 Chatbox 上游源码的源码包及 SHA-256 清单。使用和更新见 [部署说明](DEPLOYMENT.md)，测试方法与限制见 [验证记录](TESTING.md)，编辑面与剩余缺口见 [对象协议](OBJECT-EDITING.md)。

**这是候选版：Win10 21H1 / Word 2010 尚未实机验证。** 使用 Office 2010 PIA 编译及模拟版本矩阵不等于目标机通过。OLE 内部编辑、全部图表/公式节点属性、原生文档比较等仍未覆盖；132 个可发现工具也不代表所有上游边界均已认证。NuGet 在线漏洞数据源不可用，依赖漏洞审计未完成。
