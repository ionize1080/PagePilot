# PagePilot v0.3.0

修复 Word 2010 缺少 Window.Hwnd 导致侧栏和审批失败的关键路径；旧版通过本进程窗口枚举定位，歧义时拒绝猜测。

- 导航侧栏直接使用现有默认模型识别，显示分批进度、支持取消；默认自动批准目录更新，可切换手动。识别不修改文档，不再另开 AI 对话。
- 正则输入即查找、后台匹配、单击跳转、可见区域实时黄色高亮；突破 10,000 项限制，增加取消与虚拟化列表。批量替换预先核对位置、一步撤销并在失败时回滚。
- 修复超链接、目录域和内容控件附近的字符位置映射；西文字体使用 NameAscii，保留原有字号。
- 修复审批状态竞态和重复确认，按文档对象绑定；确认框主动置前；独立窗口切换仅在右上角显示。
- 减少 MCP 全篇扫描，增加上下文分页和轻量指纹；缓存标题规则、顺序遍历段落、复用编号模板；连接超时不会立即退出助手。

验证在物理机 Word 16 x64 完成：真实模型导航、真实 Chatbox 数字核稿、20 项 MCP 操作、对象工具、复杂域查找与高亮、审批和六次窗口切换均已测试。按用户要求未使用 VM；Word 2010 实机兼容性仍待确认。完整结果和性能边界见 docs/TESTING.md。

完整解压便携包，关闭 Word 后运行 Enable.cmd。保留现有模型配置和会话，包内不含密钥。提供源码包及 SHA256SUMS。
