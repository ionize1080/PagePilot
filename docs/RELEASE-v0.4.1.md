# PagePilot 0.4.1 · 部署、存储与诊断

首次部署后看不到加载项时，旧管理器只能确认注册写入，无法说明 Word 是否真正加载。0.4.1 增加实际加载验证，并改善部署阻塞、日志排查和存储配置体验。

- **关闭 Word 后继续部署**：支持请求正常关闭，或明确确认丢失未保存修改后强制关闭；只允许结束当前账户、当前桌面会话的 Word。
- **验证真实加载**：分别检查注册、Word 连接和功能区加载；显示用户、权限、Word 位数与版本、注册视图、禁用记录、策略和运行包完整性。
- **自定义存储**：独立选择运行配置文件、规则与备份目录、模型与会话目录、日志目录；可复制旧数据，保留原文件并避免覆盖已有数据。
- **详细事件日志**：覆盖部署器、Word、助手/设置窗口和 MCP；记录操作结果、耗时、错误；默认详细级别、日志轮转、一键打开文件夹和导出诊断包。
- **部署器界面更新**：清晰的三页导航、统一绿色主操作、独立危险操作与确认、操作进行中反馈；支持高 DPI 和页面滚动。
- **部署可靠性**：与 RegAsm 一致的路径表示兼容含空格目录；重复启用保留回退点；允许回退 Word 加载失败后清除连接标记的状态。旧 PowerShell 快捷脚本统一调用部署器。

下载 `PagePilot-0.4.1-portable-win-x64.zip`，完整解压到新目录，打开 `PagePilot.Manager.exe` → “启用此版本” → “启动 Word 并验证”。保留旧版本目录以便回退。无需重新填写模型参数；如更改数据位置，先阅读[配置与日志](CONFIGURATION-AND-LOGS.md)。

源代码包保留 GPL 许可证和固定版本 Chatbox 上游源码；同时提供 SHA-256 校验文件。

## 验证边界

本次在 Windows build 26300、Word 16 x64、普通用户权限下验证。Office 2010 历史日志可确认旧版曾成功连接和打开窗格；**0.4.1 尚未完成 Win10 / Office 2010 实机完整验收**，不将模拟 Word 14 能力测试当作目标环境通过。详细结果和依赖审计限制见[测试记录](TESTING.md)。

诊断包不含模型配置、聊天数据库、文档备份或工具参数正文；环境信息仍包含账户和路径。强制关闭前请先保存重要文档。运行组件需要 64 位 Windows，加载项可按 Word 32/64 位注册。
