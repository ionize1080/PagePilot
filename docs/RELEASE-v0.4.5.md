# PagePilot 0.4.5

修复长工具对话结束后第二轮被客户端拦截的问题，增强本地导航分析及目录外观设置。

## 连续对话修复

旧版 MCP 包装器把抛出的 `MCPClientError` 作为成功结果返回。首轮工具循环可以继续，但内存中的 Error 实例被放进下一轮的 JSON 工具结果，AI SDK 在请求发出前报 `AI_InvalidPromptError: The messages do not match the ModelMessage[] schema`。界面随后将其笼统显示为供应商连接失败。序列化后异常变为普通对象，因此仅测试保存/重载不足以发现问题。

- MCP 拒绝现在保持错误语义，进入工具失败处理流程。
- 历史转换识别内存异常及旧版保存的异常，保留失败原因并使用合法的错误结果格式。
- 普通工具结果经过 JSON 边界转换，不能序列化的结果显式报告失败。
- 保留上一版的 DeepSeek 推理历史、并行工具配对修复；不清空会话、不编造推理内容。
- 对此次报告涉及的会话完成本地回放校验。更新后可重试原失败消息。

## 自动导航

- 结合现有 Word 大纲、中文/英文标题样式、编号和版式证据进行本地分析，不需要 API。
- 识别中文章/节/篇及大小写中文数字、括号编号、阿拉伯多级编号、英文 Part/Chapter/Section/Appendix、英文数字词、大小写字母、ASCII/Unicode 罗马数字、全角与圈号编号，以及中英摘要、结论、参考文献等常见标题。
- 根据文档中出现的编号体系推断层级，结合字号、粗体、段前间距、居中等特征识别无编号标题；自定义规则优先，已有显式大纲/标题样式保留。
- 排除目录域重复项、普通自动列表、日期、金额及一般表格单元格等常见干扰；明确指定的表格标题仍保留。
- 插件启动及窗格绑定不扫描文档；第一次打开导航后才分批读取，纯分析在后台进行。支持“分析 / 刷新”和取消，子目录展开时才创建节点。
- 文档变化后提示更新；点击分析可重新读取文字与格式。跳转前验证文字快照，避免跳到过期位置。
- 长标题自适应换行并限制两行，悬停可查看完整文字；小窗格下避免横向裁切。

自动推断不能保证任意排版都没有误判。已有错误大纲也会被保留；可调整 Word 大纲、自定义规则，或使用现有 AI 识别。分析本身不会写入文档，只有明确点击“应用大纲”等操作才会修改文档。

## 目录外观

设置 → 阅读与导航中可分别设置 1–9 级标题的字体、字号（9–32）、粗体及颜色，并设置窗格背景色。提供即时预览、默认外观恢复和保存后的窗格更新；已展开节点保持展开。深色背景下窗格标题与状态栏自动调整对比度。

## 验证

- 使用发布包内实际 AI SDK 校验器复现旧问题，并覆盖内存异常、重载异常、普通 JSON、不可序列化结果及 MCP 拒绝传播。
- 真实 DeepSeek API 连续三轮合成工具对话通过，包含第一轮工具失败、第二轮继续、第三轮重载后的历史；未向 API 发送用户文档或真实会话内容。
- 45 项导航检查及 17 项原核心检查通过。50,000 段纯分析约 45 ms；这是内存分析时间，不包含 Word COM 读取或界面构建。
- 本机真实 Word 16 x64 中验证了提供的文档八个主要章节、定位、文档只读保持、展开加载、样式应用及取消。
- 窗格绑定单次约 0.4–0.6 秒且不扫描；测试程序跨进程读取该文档约 8 秒，期间分批让出界面。安装后的实际 Word 内加载项验证：新窗格调用约 583 ms 返回，77 段分析约 2,735 ms；单次样本，不把内存算法耗时当作整体耗时。
- 144 项部署回归通过；本地新版注册和新启动 Word 实际加载 0.4.5、命名管道连接、只读文档导航验证通过。
- 设置界面 620/880 像素宽度布局及九级样式保存检查通过。
- Release 编译使用本地缓存依赖；本机 NuGet 漏洞数据源代理不可达，未完成在线漏洞审计。

本次验证环境为 Word 16 x64；Office 2010 完整实机兼容性仍需目标机验证。

## 更新

关闭 Word，解压便携包至新目录，运行 `PagePilot.Manager.exe` 启用。原模型配置、密钥和会话继续使用本机数据目录。保留旧目录可回退。提供便携包、含固定 Chatbox 上游源码的 source 包和 SHA256SUMS。
