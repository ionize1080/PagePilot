# PagePilot v0.2.0

本次更新集中改善外观、阅读定位、AI 窗口切换与操作批准，并补齐实时文档对象操作。

- 新绘制文档星芒、正则搜索、书签、齿轮图标，提供翡翠、海蓝、石墨三套配色与设置预览；功能区及原生侧栏同步更新。
- AI 助手可在 Word 侧栏与独立窗口间切换，保留会话和草稿；侧栏隐藏多余窗口控制，顶部与输入栏都提供切换按钮。
- 设置采用左侧导航、右侧内容布局，独立启动；仅主动进入模型设置才打开 Chatbox。
- 输入栏盾牌表示手动批准，二次确认后显示红色闪电；自动批准仅限当前文档、本次 Word 会话。确认会等待明确选择。正则替换、手动应用大纲直接执行并备份。
- 自动导航采用可折叠层级树、单击定位，标题移到阅读区域上部；顶部留白可调，按钮占用缩小。AI 目录要求可指定只识别大标题或全部层级，结果不改变文档样式。
- MCP 全量提供 120 个上游工具与 9 个 PagePilot 扩展，共 129 项。新增逐工具版本指导、对象检查，以及实时脚注、尾注、目录、域、内容控件操作。Word 2010 不支持的评论回复/解决会提前拦截。

完整解压 `PagePilot-0.2.0-portable-win-x64.zip`，关闭 Word 后运行 `Enable.cmd`。仅注册当前用户 COM/Word 加载项，无安装向导、MSI 或“已安装的应用”条目。设置和会话留在原数据目录；压缩包不含 API Key 或个人会话。MCP 仅使用 stdio，内部为命名管道，不开放 HTTP/TCP 服务端口。

真实 DeepSeek API、Chatbox 发送链路、Word 对象回读、窗口切换、取消/确认批准、导航与正则界面均纳入验证。详见 [测试记录](TESTING.md) 和 [MCP 覆盖说明](MCP-COVERAGE.md)。

**实测环境是 Windows build 26300、Word 16.0.20430.20180 x64。Win10 21H1 + Word 2010 暂无目标测试环境，兼容性仍未实测。** 129 项完整接口不等于已逐一验证全部上游行为。复杂嵌套表格、大文档、多进程和混合 DPI 仍需扩展验证；NuGet 在线漏洞数据获取在本机不可用。上游签名工具是元数据，不是证书签名。

源码包包含固定 Chatbox 1.20.3 源码归档及完整 Word MCP 源码；许可证与 SHA-256 校验值随包提供。
