# PagePilot 0.4.9

修复首次发送消息后工作区文件列表消失的问题，并新增后台原生 Excel 分析。

- 首次发送时先完成草稿工作区与新聊天的关联，再进入聊天。参考文件和分析底稿保持可见，切换聊天、重载和重启后仍能正确读取。
- 新增 Excel 能力查询、区域读取和批量编辑工具，工作区 MCP 现提供 11 个工具。
- 支持新建、复制、重命名、删除工作表，区域读写、公式填充、表格、排序、筛选、去重、格式与图表。
- 支持清洗、查找合并、缺失值处理、描述统计和相关分析，保留来源与操作记录。
- 创建真正的 Excel 原生透视表，支持行/列/筛选字段、多项汇总，以及刷新或调整数据源；可在 Excel 中继续编辑和刷新。
- 原生操作使用独立、不可见的后台 Excel，只保存新的分析副本；不会覆盖来源文件。超时或失败会清理本次创建的 Excel 进程，不关闭已有用户实例。
- 默认采用 Excel 2010 兼容公式和透视表格式。安装新版 Excel 时，逐项探测新版函数后可显式启用；2010 环境可通过清洗、查找、排序、筛选等工具生成兼容结果。
- 保持准便携 ZIP 与部署管理器方式。更新按版本使用新目录，沿用原有配置、聊天和工作区；管理器版本显示与程序集版本保持一致。

已使用真实 DeepSeek API，经实际 Chatbox 输入框、stdio MCP 和本机 Excel 创建工作表、公式、原生透视表与统计结果；文件列表持续可见，源文件哈希不变。另通过真实 Excel 回归、工作区解析和 UI 回归。详见 [验证报告](TESTING-v0.4.9.md)。

原生编辑需要本机安装 Excel，离线分析仍可在未安装 Excel 时使用。实际验证环境为 Word 16 x64 和 Excel 16.0；Windows 10 21H1、Word 2010、Excel 2010 标准版尚未完成目标机验收。兼容模式不会给 Excel 2010 增加 Microsoft 365 引擎；Power Query、数据模型/Power Pivot、Python in Excel、Copilot 不在本版自动化范围。具体能力、限制与使用方式见 [工作区说明](WORKSPACES.md)。
